03 · 설계 결정

“저장”이 아니라
“그 영상에 대한 내 생각”을 쌓는 앱

04 · 화면 시연 ① 시작과 저장

쓰는 흐름 그대로

영상을 보다 링크를 붙여넣고, 한마디를 남기면 끝. 저장한 기록은 상세 화면에서 원본 영상을 열거나 링크를 공유할 수 있어요.

수정 기능 직접 제안

영상 링크는 그대로 두고 제목·내 생각·태그만 고치게 했어요. 버튼은 기록을 읽는 데 방해되지 않게 닫기(X) 옆 연필 아이콘으로 옮겼습니다.

공유 기능 직접 제안

종이비행기 버튼을 누르면 원본 링크와 [복사하기]가 뜨도록 만들었어요. 써 보니 연필 버튼과 헷갈려, 지금은 하단 ‘링크 공유’ 버튼으로 옮겼습니다.

05 · 화면 시연 ② 훑어보고 찾기

쌓인 기록을
개인 피드처럼

기록이 쌓이면 피드처럼 쭉 내려 보며 훑고, 필요할 땐 태그를 눌러 원하는 것만 모아 봅니다. 제목·코멘트·태그를 한 번에 찾는 검색도 있어요.

  • 보기2열 카드 피드 ↔ 목록 보기카드 높이 고정
  • 태그#AI, #게임, #여행 … 누르면 그것만지인이 가장 좋아한 기능
  • 검색제목·코멘트·태그 종합 검색영상 속 예시 · “선물”

썸네일이 없는 틱톡 기록(겨울 코디)은 태그를 보고 고른 기본 이미지로 보입니다.

07 · 설정 탭

“코드를 잃어버리면?”에서
시작한 설정 탭

로그인 없이 코드 하나로 여는 구조라, 연결이 끊기면 코드를 다시 찾을 방법이 없었어요. 앱 안에서 내 코드를 다시 보는 기능을 제안한 것이 설정 탭의 시작이었습니다.

보관함 코드 보기·복사 직접 제안

“연결 해제가 되면 코드를 찾을 방법이 없잖아?” 앱 안에서 언제든 코드를 확인하고 복사할 수 있게 했어요.

팝업으로 열기 직접 제안

화면이 아래로 밀리지 않고 새 인용처럼 겹쳐 뜨게. 배경은 덜 어둡게 남겨 테마가 바뀌는 걸 바로 보이게 했어요.

기록 백업 직접 제안

구글 계정 백업을 구상했고, 먼저 기록 전체를 파일로 내보내는 백업으로 구현했어요.

공유용 코드 직접 제안설계까지

태그를 골라 읽기 전용으로 보여 주는 코드. 수정·삭제는 막는 구조까지 설계했고, 아직 구현하지 않았어요.

08 · 문제 해결

막혔던 장면 셋

기록이 사라진 듯 보였다

며칠 뒤 앱을 켜니 아이폰에 저장한 기록이 보이지 않았습니다. 지워진 게 아니라, 와이파이가 바뀌며 접속 주소가 달라졌고 기록은 주소마다 따로인 브라우저 공간에 있었어요. 어디서 열어도 같은 기록이 보이게 서버 저장(Supabase)으로 옮기고, 로그인 대신 보관함 코드를 택했습니다.

돈 쓰지 않고 썸네일 띄우기

인스타그램 썸네일은 유료 API부터 시험했지만, 계속 쓰면 비용이 든다는 걸 알고 “다른 방법 없을까?” 다시 물었습니다. 공개 게시물의 미리보기 이미지를 서버에서 직접 읽는 무료 방식으로 바꿔, 릴스와 일반 게시물 모두 띄웠습니다.

다른 기록이 덮어써졌다

수정과 닫기를 반복하며 테스트하다, 2번째 기록이 1번째 기록 내용으로 바뀐 걸 발견했습니다. 더 수정하지 않고 증상(링크는 그대로, 닫아도 수정 화면이 남음)을 정리해 원인을 좁혔고, 수정 대상을 고정하고 닫을 때 상태를 비우게 고쳤습니다.

그 밖에 : 서버 연결이 안 되던 문제(서버 로그에 요청이 없다는 단서로 환경설정 파일의 오타를 찾음), 연필 아이콘이 기기마다 다르게 보이던 문제(특수문자 → SVG 아이콘), 배포 후 기본 배경색이 예전 색으로 나오던 문제(코드의 기본값이 예전 색으로 남아 있었음).

11 · 회고

AI는 구현을 도왔고,
문제 발견과 방향 결정은 내가

잘한 점 AI의 제안에 끌려가지 않고 방향·기능·색을 먼저 제안했고, 직접 써 보며 문제를 찾아 고쳤어요. 그 과정에서 AI 웹앱이 기획부터 배포까지 어떻게 만들어지는지 직접 체득했고, AI를 ‘도구를 만드는 도구’로 적절히 활용했습니다. VS Code에서 코드를 직접 고쳐 보며 기초 코딩도 배웠어요.

아쉬운 점 읽기 전용 ‘공유용 코드’는 설계까지만 했어요. 누구나 보관함을 만들 수 있고 글자 수 제한·복원 기능이 없는 점도 대중 공개 전에 채워야 할 빈칸입니다.

다음 지인이 꼽은 ‘링크 붙여넣기의 번거로움’부터 줄이고, 데이터가 안전하다는 확신이 들면 공개 범위를 넓히기.

지인에게 먼저 공개

개인의 기록을 다루는 앱이라, 데이터가 날아갈까 봐 대중 공개는 미루고 지인에게만 써 보게 했어요.
